# fonts

자주 쓰는 Variable 폰트. 새 프로젝트에 복사해서 쓴다.

| 파일 | 용도 |
|------|------|
| `PretendardVariable.ttf` | Pretendard Variable (1.3.9) |
| `SUIT-Variable.ttf` | SUIT Variable |
| `LICENSE.Pretendard.txt` | Pretendard 라이선스 |
| `LICENSE.SUIT.txt` | SUIT 라이선스 |

## 가져가기

- 웹: `public/fonts/` 또는 `assets/fonts/` 등으로 복사 후 `@font-face` / `next/font/local`
- Android: `res/font/` 또는 assets에 두고 Compose/XML에서 로드 (Variable 지원 여부는 스택에 맞게)

라이선스 파일도 프로젝트에 같이 두는 걸 권장.

출처 (로컬):
- Desktop `Pretendard-1.3.9/public/variable/`
- Desktop `SUIT-Variable-ttf/`
